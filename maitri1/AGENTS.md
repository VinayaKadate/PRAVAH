# Agent Instructions & Project Rules

- **Domain Specificity**: The backend and database must be strictly tailored to the MAITRI (Maharashtra Industry, Trade and Investment Facilitation Cell) Single Window Clearance System only.
- **Data Models**: All entities must strictly model MAITRI workflows: Common Application Forms (CAF), departmental approvals (MIDC, MPCB, DISH, Fire Services, MSEDCL, Revenue), desk-level SLA tracking, PSI 2019 incentive claims, and statutory grievance redressal under the Maharashtra Right to Public Services Act.
